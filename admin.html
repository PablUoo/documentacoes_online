Configurar acesso

O token do GitHub fica salvo no repositório criptografado com o usuário e a senha que você escolher aqui. Depois disso, basta entrar com usuário e senha.

Use pelo menos 8 caracteres. Quanto mais longa, mais segura.
Pedido só nesta configuração. Crie em GitHub → Settings → Developer settings → Fine-grained tokens, só para este repositório, com permissão Contents: Read and write.
É o endereço usado nos QR Codes. Em branco, usa o endereço desta página.
